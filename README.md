🚀 MAMA Chatbot – A supportive AI-powered chatbot designed for postpartum women, offering mood-based conversations, journaling, baby milestone tracking, self-care reminders, and personalized assistance.

MAMA Chatbot - Your Postpartum Companion

MAMA Chatbot is an AI-driven virtual assistant designed to support postpartum women by providing personalized emotional support, baby milestone tracking, self-care reminders, and interactive journaling.

✨ Key Features:
✅ Mood-Based Conversations – If a mom is feeling stressed, anxious, or happy, the chatbot tailors its responses to provide comfort and encouragement.
✅ Daily Journal – Moms can write and save their thoughts, moods, and experiences, which the chatbot can later reference.
✅ Baby Milestones Tracker – Store and retrieve important moments like the first smile, first steps, and more.
✅ Self-Care Reminders – Automated reminders for hydration, relaxation, and self-care.
✅ Scheduler for Baby Activities – Track feeding times, playtime, and doctor appointments.
✅ GPT-Powered Smart Assistance – Reads through journal entries to provide personalized responses when the user asks about past experiences.
✅ Real-Time Updates with Firebase Firestore – Ensures journal entries and milestones sync instantly across devices.

🚀 Tech Stack Used:
Frontend: React.js (Tailwind CSS for UI)
Backend: Node.js + Express.js
Database: Firebase Firestore (for real-time storage & chatbot queries)
Authentication: Firebase Auth
Hosting: Firebase Hosting
AI/NLP: OpenAI GPT integration (for smart chatbot responses)

💡 How It Works:
1️⃣ The chatbot detects the user's mood and suggests uplifting conversations if needed.
2️⃣ Moms can write their daily journal, which is stored securely.
3️⃣ The chatbot can search through past journals to answer personal questions.
4️⃣ Baby milestones and self-care reminders help moms stay organized.
5️⃣ Firebase syncs data across devices in real-time for easy access.

❤️ Why This Project?
Postpartum moms often lack emotional support and feel overwhelmed with new responsibilities. MAMA Chatbot bridges this gap by providing a safe space for self-expression, tracking milestones, and getting AI-powered assistance.
